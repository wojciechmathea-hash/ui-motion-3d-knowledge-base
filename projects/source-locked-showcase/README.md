# Source Locked Showcase

Poglądowa, interaktywna strona scrollytelling bez WebGL. Cała warstwa wizualna jest złożona z komponentów Magic UI Free i ich jawnych zależności zapisanych w `SOURCE_LOCK_MANIFEST.md`.

## Uruchomienie

```powershell
npm install
npm run dev
```

Eksport statyczny powstaje po `npm run build` w katalogu `out/`.

## Kontrola

```powershell
npm run lint
npm run build
```
