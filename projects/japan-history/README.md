# Japonia — historia zapisana w krajobrazie

Samodzielna strona HTML oparta na zatwierdzonym komponencie ThreeUI Kage. Wszystkie zależności wizualne są lokalne; projekt nie wymaga instalacji pakietów ani połączenia z siecią do uruchomienia głównego doświadczenia.

## Uruchomienie

Najprościej otworzyć `index.html` bezpośrednio w nowoczesnej przeglądarce. Dla pełnego zachowania WebGL można uruchomić dowolny lokalny serwer HTTP w tym katalogu, np. `python -m http.server 3010`.

## Dokumentacja

- `BRIEF.md` — narracja, źródła faktów i kontrakt jakości;
- `SOURCE_LOCK_MANIFEST.md` — pochodzenie każdego widocznego i interaktywnego elementu;
- `VISUAL_LAYER_STACK.md` — mapa warstw WebGL i 2.5D;
- `provenance/` — rekord komponentu i źródła treści;
- `THIRD_PARTY_NOTICES.md` oraz `licenses/` — licencje i noty.
