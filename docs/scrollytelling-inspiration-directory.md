## Jak korzystać

1. Wybierz jedną realizację ze względu na problem narracyjny, nie estetykę.
2. Zapisz mechanikę abstrakcyjnie, np. „sticky wykres + pięć kroków hipotezy”.
3. Odtwórz mechanikę z zatwierdzonych komponentów lub lokalnych generatorów open source.
4. Zbuduj wersję statyczną, mobile i reduced-motion przed dodaniem pełnego ruchu.
5. Nie kopiuj layoutu 1:1, charakterystycznych ilustracji, treści, kodu ani identyfikacji marki.
