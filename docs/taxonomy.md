# Taksonomia bazy

Każdy wzorzec może należeć do wielu kategorii. Nazwa kategorii opisuje rolę w produkcie, a tagi opisują technologię i zachowanie.

## Kategorie funkcjonalne

- `layout`: grid, bento, sekcje, split view, masonry.
- `navigation`: navbar, dock, menu, tabs, breadcrumbs, pagination.
- `input`: formularze, pola, przełączniki, suwaki, drag controls.
- `action`: button, CTA, command, contextual action.
- `data-display`: karty, listy, tabele, tree, terminal, statystyki.
- `feedback`: loader, progress, notification, empty/error/success state.
- `overlay`: modal, popover, tooltip, drawer, command palette.
- `media`: gallery, carousel, poster wall, device mockup.
- `marketing`: hero, social proof, pricing, feature, FAQ, footer.

## Kategorie motion

- `microinteraction`: hover, press, focus, toggle, drag feedback.
- `transition`: wejście/wyjście, shared layout, route transition.
- `timeline`: sekwencje i choreografia wielu elementów.
- `scroll`: reveal, scrub, pin, parallax, velocity response.
- `text-motion`: type, split, morph, scramble, rotate, marquee.
- `svg-motion`: draw, morph, path following.
- `cursor`: trail, magnetic target, spotlight, custom cursor.

## Kategorie 3D i generative

- `threejs-scene`: geometria, kamera, światło, model i interakcja.
- `shader`: fragment/vertex shader, procedural material, post-processing.
- `particles`: CPU/GPU particles, flow field, trails.
- `simulation`: fluid, cloth, physics, reaction-diffusion.
- `3d-ui`: globe, carousel, gallery, spatial navigation.
- `generative-art`: algorytmiczny wzorzec, noise, field, topology.
- `immersive-background`: pełnoekranowa scena wspierająca treść.

## Tagi techniczne

`react`, `typescript`, `tailwind`, `css`, `svg`, `canvas-2d`, `webgl`, `threejs`, `motion`, `animejs`, `glsl`, `r3f`, `client-only`, `gpu-heavy`.

## Tagi jakościowe

`keyboard`, `screen-reader`, `reduced-motion`, `touch`, `mobile-safe`, `fallback-required`, `pause-offscreen`, `high-contrast`, `content-first`.

## Skala intensywności

- `1-subtle`: feedback i delikatne podkreślenie stanu.
- `2-supporting`: ruch wspiera hierarchię, ale nie dominuje.
- `3-hero`: główny akcent jednej sekcji.
- `4-immersive`: doświadczenie jest zbudowane wokół ruchu/3D; wymaga zgody projektowej i fallbacku.
